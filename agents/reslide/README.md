# Reslide Agent — 使い方（Claude 運用ガイド）

**イマイチなデザインの既存スライド（PPTX/PDF）を、OpenAI（gpt-image）で高品質に作り替える**エージェント。中身（文言・数字）は忠実に保ち、見た目だけ生まれ変わらせる。官公庁パワポのような詰め詰めページは**話題ごとに複数枚へ自動分割**する。

**このREADMEは Claude Code が読んで、ユーザーを対話誘導するための運用指示です。**

---

## 全体フロー（Claude はこう誘導する）

0. **入口ガイド** — 「デザインがいまいちなスライド、**中身そのまま・見た目だけ作り替え**できます。PPTXかPDFをください。画風はこちらで提案します（おまかせOK）」
1. **ファイルを受け取る** — PPTX / PDF
2. **中身の抽出（課金ゼロ）** — 各ページを vision で読み「書いてある文言・数字だけ」を構造化。**1ページに複数話題があれば自動で分割**（元の枚数より増えることも）。抽出漏れ照合つき。
3. **画風を決める** — 6種から指定 or 保存名で使い回し or **AIが内容から提案**
4. **概算 → 承認** — 「◯枚で約◯円」→ OK なら gpt-image で作り替え
5. **仕上げ** — 文字照合（vision・課金ゼロ）で数字・文言のズレを検査 → 指摘があれば `slide fix` で該当枚だけ再描画
6. **納品** — before（元ページ）/ after を並べて見せる。PDF・画像PPTX付き

## コマンド早見表

`python studio-agents/agents/reslide/cli.py build …`（リポジトリ直下から）。

| フラグ | 意味 | 未指定なら |
|---|---|---|
| `--file 資料.pptx` | 元スライド（PPTX/PDF）【必須】 | — |
| `--theme` | 画風（テーマ名 or **保存名**） | AIが内容から提案 |
| `--save-style NAME` | 今回の画風を名前で保存（使い回し用） | — |
| `--approved` | gpt-image の課金を承認して実行 | 概算だけ返して停止 |
| `--regen` | 中身の抽出からやり直し | 抽出済み deck.json を再利用 |
| `--out` | 出力先 | ./out |

## 品質の担保（全部課金ゼロ）

- **忠実抽出**：ページに書いてある文言・数字だけ（創作しない）
- **分割**：詰め詰めページは1話題=1スライドに分割。**内容は捨てずに全部割り当てる**
- **カバレッジ照合**：どのスライドにも入らなかった内容を検出（deck.json の `coverage`）
- **文字照合**：描き直し後、数字・文言が正しく描かれたか vision で検査

## 課金

gpt-image 約1.5〜2円/枚。**概算 → `--approved` の2段**（承認前は1円も使わない）。生成済み `sXX.png` はキャッシュされ再実行で再課金なし。

## 出力物

- `sXX.png`（作り替え後）/ `deck.pdf` / `deck.pptx`（画像貼り）
- `pages/`（元ページ＝before比較用）
- **`deck.json`** — Slide 互換の箱。`slide fix --deck deck.json`（指摘枚だけ再描画）や **Slidecast（動画化）にそのまま繋がる**

## 依存

vision抽出＝claude CLI（課金ゼロ）、PPTX→PDF変換＝LibreOffice、ページ画像化＝PyMuPDF、作り替え＝OPENAI_API_KEY【必須】。`setup_check.py` で診断可。
