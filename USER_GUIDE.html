studio-agents 全体像

5つのAIエージェント — ユーザーから見た導線・選べるオプション・課金ポイント。
使い方はすべて「Claudeに話しかけるだけ」。コマンドや型の名前を覚える必要はありません。

全エージェント共通のルール

素材の権利取り込む資料・URL・記事は、自分が権利を持つもの、または利用許諾のあるものに限ります。第三者の記事・ニュースは、要約と出典明記の範囲で扱ってください
会話で完結「この資料でスライド作って」「このURLを動画にして」——Claudeが必要なことだけ聞き、あとは提案してくれる
おまかせOK決めていない項目(型・画風・声など)はAIが中身を見て提案。こだわる時だけ「投資家向けに固く」のように言えば反映
課金は必ず事前承認お金がかかる工程(AI画像・音声合成)は「◯枚で約◯円です。進めますか？」→OKしてから実行。承認前は1円も使わない
画風の使い回し気に入った画風は名前を付けて保存。「前と同じテイストで」「◯◯の画風で」で再現できる(全エージェント共通の保存庫)
作り直しに強いナレ・絵コンテ・画像は保存され、再ビルドは差分だけ課金(例: 声だけ変える=数円)。作り直したい所だけ「--regen」で更新

① Slide — テーマ/資料 → 高品質スライド

入力: テーマ・PDF/PPTX/DOCX・URL・メモ(複数可) → 出力: スライド画像・編集可能PPTX・PDF + deck.json(動画化への引き継ぎ)

🗣 「この事業計画で投資家向けのスライド作って」
🤖 「構成=ピッチ・画風=midnightが合いそうです → 6枚できました(編集可PPTX付き)。AI画像版なら約8円でもっと見栄えが出ますが、どうしますか？」
選べるもの選択肢未指定なら
宛先誰の資料/誰に見せる/目的/トーン(自由記述も可)AIが推定
構成(話の型)コンサル提案サービス紹介導入事例ピッチ教育・解説報告まとめAIが提案
画風明朝エグゼクティブミッドナイトコーラルウォームセリフモダンサンスインディゴAIが提案
描画モードテンプレ版(編集可PPTX)=無料 / AI画像版(gpt-image)=約1.5円/枚AI画像版まで作るのが標準(承認制)
手直しデザイン自己改善 / 1枚だけ型変更 / 文字照合→指摘枚だけ再描画—

② Blog — テーマ/資料 → 図解付きブログ記事

入力: テーマ・資料・URL(複数可) → 出力: 図解付きHTML(WordPress貼り付け可)・Markdown + article.json(動画化への引き継ぎ)

🗣 「この社内メモ、初心者向けのブログにして」
🤖 「型=やさしい解説・画風=コーラルで書きますね → 2500字・8節できました。捏造チェックで該当文を除去済み。各節に解説図を付けると8枚で約10円ですが、付けますか？」
選べるもの選択肢未指定なら
記事の型やさしい解説ハウツー◯選まとめ比較事例・体験談ニュース解説オピニオンAIが提案
モード/長さ長文SEO(肉付けあり・既定) / 元ネタ忠実(短め)、目標字数SEO 3500字
画風(図解用)Slideと同じ6種AIが提案
品質ゲート捏造除去・水増し圧縮・焦らし解消(自動・無料)常に実行
図解各節を「内容入りの解説スライド図」に(約1.5円/枚・承認制)図付きHTMLまでが標準(承認制)

③ Reslide — 見づらいスライド → 作り替え

入力: 既存のPPTX/PDF → 出力: 作り替え後のスライド一式(PNG/PDF/PPTX) + before比較用の元ページ + deck.json

🗣 「この行政資料風のパワポ、きれいに作り替えて」
🤖 「1ページに話題が詰まっているので複数枚に分割して整理します。画風=明朝エグゼクティブ、約20円ですが進めますか？ → 完成。数字の照合も全通過です」
特徴内容
詰め詰め対策1ページに複数話題があれば話題ごとに自動分割(1枚→数枚)。内容は捨てずに全部割り当て
忠実さの保証中身の抽出は「書いてある文言・数字だけ」+ 抽出漏れ照合 + 描画後の文字照合(全部無料)
画風6種から指定 or AIが提案(保存・使い回し可)
課金gpt-image 約1.5円/枚(承認制)。指摘が出た枚だけの再描画も可

④ Slidecast — スライド → 解説動画

入力: Slide/Reslideの成果物(deck.json) または手持ちのPPTX/PDF → 出力: 解説動画 mp4(1080p・字幕付き)

🗣 「このスライド、動画にして」
🤖 「声はおまかせなら設定済みの声で。ナレを作りました——音声合成で約1.5円、動画にしていいですか？ → 完成。声や台本を変えたければ言ってください」
選べるもの選択肢未指定なら
入力deck.json(①③の出力) / 手持ちPPTX・PDF(そのまま動画化)—
声(6種・別環境でも同じ声を再現可)Nao 男・明るい説明Shohei 男・落ち着きRen 男・なめらかMiki 女・明るいMaya 女・クリアKazuha 女・温かい設定値(未設定なら指定を求める)
映像静止スライド+白フェード切替+黒帯字幕(音声同期・字幕はフェードしない)固定仕様
ナレーションAIが生成(無料)して固定保存——再ビルドでも同じ内容。作り直しは指示すればOK自動生成
課金ElevenLabs音声のみ(数百字で1〜2円・承認制)—

⑤ Blogcast — 記事/URL → 台本の型付き動画

入力: 記事URL / Blogの成果物(article.json) / テキスト → 出力: 解説動画 mp4(自由なイラスト画・字幕付き)

🗣 「この自社ブログ記事、動画にして」
🤖 「台本の型はビフォーアフター型が合いそうです。画風は"手描き風・生活感"を提案します。画像8枚+音声で約20円、進めますか？ → 完成」
選べるもの選択肢未指定なら
台本の型(7種)記事忠実・実用記事忠実・物語結論3つ先出し悩み解決ビフォーアフター謎引っぱり◯個まとめAIが記事を読んで提案
画風自由文のアートディレクション(スライド風でない情景イラスト)。保存名で使い回し可AIが記事から提案
声Slidecastと同じ6種設定値(未設定なら指定を求める)
作り直し絵コンテ(ナレ・画)は固定保存。画像はキャッシュされ、声だけ変える再ビルドは数円—
課金gpt-image 約2円/枚 + 音声1〜4円(合算概算→承認制)—

環境まわり

初回は「セットアップ確認して」と言えば、Claudeが診断スクリプトで足りないもの(ffmpeg・LibreOffice・APIキー等)を洗い出し、1つずつ確認しながら導入します。使うエージェントの分だけ揃えばOK(①②は軽量、④⑤は動画用の追加ツールが必要)。
